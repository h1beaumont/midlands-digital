# Midlands Digital

Website for Midlands Digital, an AI automation consultancy for small businesses in the Midlands. Live at [midlandsdigital.ai](https://www.midlandsdigital.ai).

Includes a live AI demo, a blog served from the API, and a contact form that emails enquiries through Resend.

## Stack

- React, Vite, TypeScript, Tailwind and shadcn/ui on the front end
- Express API bundled with esbuild and deployed as a Vercel serverless function
- OpenAI for the demo assistant

## Running locally

```
npm install
npm run dev
```
